# Contributing to Awesome Video to Text

Thank you for your interest in contributing! This project aims to be the most comprehensive collection of AI skills for video-to-text processing.

## How to Contribute

### Adding a New Skill

1. Fork this repository
2. Create a branch: `git checkout -b add/new-skill-name`
3. Choose the appropriate category folder:
   - `skills/转录技术/` - Transcription skills
   - `skills/内容提取/` - Content extraction skills
   - `skills/笔记整理/` - Note organization skills
   - `skills/字幕处理/` - Subtitle processing skills
   - `skills/学习辅助/` - Learning aid skills
4. Follow the skill file template below
5. Submit a Pull Request

### Improving Existing Skills

- Fix typos or broken links
- Update outdated tool versions
- Add new code templates
- Improve Chinese translations
- Add real-world examples

### Reporting Issues

- Use the appropriate issue template
- Include as much detail as possible
- For tool compatibility issues, specify OS and tool versions

## Code Style

- Use Markdown consistently
- Include both English and Chinese content
- Code examples should be runnable
- Use fenced code blocks with language identifiers
- Keep line lengths reasonable

## Pull Request Process

1. Ensure your skill file follows the template
2. Update the README.md skills table if adding a new skill
3. Update CHANGELOG.md with your changes
4. Ensure all links are valid
5. PRs require at least one review before merging

## Code of Conduct

## 贡献指南
